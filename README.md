# open-in-ya-browser

Страница-редирект, которая пытается открыть **захардкоженную** ссылку в
**Яндекс.Браузере**, а если приложение не установлено — отправляет пользователя
в магазин приложений (App Store на iOS, Google Play на Android).

Сейчас целевая ссылка — `https://ya.ru`.

## Зачем захардкожено

Страница намеренно **не** принимает целевой URL из параметров запроса. Иначе её
можно было бы использовать как открытый редирект (фишинг, обход фильтров: твой
домен в адресе, а уводит куда угодно). Открывается строго одна заданная ссылка.

## Как сменить цель

Отредактируй одну строку в начале скрипта в `index.html`:

```js
var TARGET_URL = "https://ya.ru";
```

## Как это работает

- **iOS** — пробуем открыть схему `yandexbrowser-open-url://<base64(url)>`.
  Если за ~1.5 с страница не ушла в фон (приложения нет), редиректим в App Store.
- **Android** — используем `intent://…;package=com.yandex.browser;…` со встроенным
  `S.browser_fallback_url`, ведущим в Google Play, если браузер не установлен.
- **Десктоп** — показываем кнопку для перехода по обычной ссылке.

## Настройка

Идентификаторы приложения и таймаут фолбэка задаются в начале скрипта в `index.html`
(`TARGET_URL`, `APPSTORE_URL`, `PLAYSTORE_WEB`, `ANDROID_PACKAGE`, `IOS_SCHEME`,
`FALLBACK_TIMEOUT`).
